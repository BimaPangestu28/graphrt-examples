# graphrt-examples
Example apps for graphrt (Flutter, React Native) — chatbot on graphrt serve + Supabase

- [supabase-chatbot/flutter](supabase-chatbot/flutter/) — Flutter client: Supabase login, streamed chat from graphrt serve, history in Supabase.
- [supabase-chatbot/react-native](supabase-chatbot/react-native/) — Expo (React Native) client: Supabase login, streamed chat from graphrt serve, history in Supabase, token refresh and retry with backoff.
